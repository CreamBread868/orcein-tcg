## セットアップ
1. Googleスプレッドシートを1つ作成。
2. 拡張機能 → Apps Script を開く。
3. 上記5ファイルを作成して内容を貼り付ける。
4. `Code.gs` の `CONFIG.SPREADSHEET_ID` を空欄のままにする場合、そのスプレッドシートに紐づいたGASプロジェクトで使用する。
   - スタンドアロンGASの場合はスプレッドシートIDを設定。
5. `doGet()` をWebアプリとしてデプロイ。
6. 初回アクセス時に `Cards` シートが自動作成される。

## 注意
Google Drive画像アップロードは、Apps Scriptの権限とGoogle Workspace管理者の共有設定によって「リンク共有」が禁止されている場合があります。
その場合でもDrive上には保存されますが、画像URLによる直接表示ができないことがあります。

=== 管理者ログイン ===
1. Apps Scriptエディタで Code.gs を開く。
2. 関数一覧から setupAdminPassword を選ぶ。
3. 8文字以上のパスワードをコード内の引数にして一度だけ実行する：setupAdminPassword('自分で決めた強いパスワード')
4. Webアプリを再読み込みし、右上の「管理者ログイン」からログインする。
5. カード作成・編集・削除・画像アップロードは管理者ログイン中だけ実行できる。

※パスワードはスプレッドシートには保存せず、Apps ScriptのスクリプトプロパティにSHA-256ハッシュとして保存します。
※カード効果は自由記述できます。「効果アシスタント」で基本効果の文章を自動生成することもできます。
※将来のバトル処理では、自由なJavaScriptを直接evalせず、安全な「効果コード(Action DSL)」を追加してゲーム内アクションに接続する設計を推奨します。

【今回の変更：効果エディター】
・特性、ワザ1、ワザ2に「効果エディターで設定」を追加。
・「すること」「対象」「数値」を選択して効果を作成可能。
・複数の効果を追加でき、↑↓で順番変更、削除も可能。
・生成された日本語テキストを効果欄へ自動反映。
・実行用の効果データはJSONとして abilityCode / attack1Code / attack2Code に保存。
・対応効果：ダメージ、HP回復、ドロー、エネルギー付与、入れ替え、手札破棄、サーチ、ダメージ軽減、ダメージ増加、にげるコスト軽減。
・保存時に効果JSONをサーバー側でも検証。


【今回の追加】
- ActionEngine.js.htmlを追加しました。
- abilityCode / attack1Code / attack2Code のJSONを、許可された効果だけ実行するための基盤です。
- 任意のJavaScript(eval)は実行しません。
- 効果エディターで設定したJSONを、将来のバトル処理から実行できる構造にしています。
